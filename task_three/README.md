# DATA WRANGLING PROJECT (STUDENT SCORES)

## Project Overview

This project involves the following:

1. **Data loading**: Loading the `student-scores.csv` file into a Pandas DataFrame.
2. **Data Cleaning:**
    * Dropping empty rows
    * Removing duplicate rows.
3. **Feature Engineering:**Creating a new column "average-score" to get the average score of every student
4. **Data Exploration:**Getting actionable insights and detecting trends and patterns
5. **Report Generation:**Creating a markdown report summarizing the findings.
    
## Files

* `student-scores.csv`: The original dataset.
* `task three.ipynb`: The jupyter file
* `README.md`: This file.


## Dependencies

* Python 3.x
* Pandas
* NumPy
* Matplotlib

## Results

The processed data provides insights into factors affecting the average score of students.
